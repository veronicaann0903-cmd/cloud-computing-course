# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of on-demand cloud services. These services allow organizations to build, deploy, store, and manage applications and data without having to maintain all of their own physical infrastructure.

## 2. Global Infrastructure

AWS operates a global cloud infrastructure made up of Regions and Availability Zones. AWS Regions are geographic areas, while Availability Zones are separate locations within a Region designed to help applications achieve greater availability and reliability.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create resources, configure services, monitor their cloud environment, and manage their AWS account.

## 4. Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving files, data, backups, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create and manage a logically isolated network environment within AWS.

### 4. Amazon RDS

Amazon Relational Database Service (RDS) provides managed relational databases that can be used by applications.

## 5. Three Advantages

1. AWS provides a broad range of cloud services for different computing and business requirements.
2. AWS can scale resources according to changing workloads and application requirements.
3. AWS provides a global infrastructure that can support applications used by organizations in different locations.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for application hosting, data storage and backup, database management, website hosting, data analytics, and scalable business applications.
