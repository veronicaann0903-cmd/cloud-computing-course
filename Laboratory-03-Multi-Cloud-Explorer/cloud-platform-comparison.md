## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, networking, databases, security, and many other areas. This makes AWS a strong choice for organizations that need many different cloud capabilities from one provider.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already use Microsoft technologies. Its services are designed to work closely with products and technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes-related workloads. Google has significant experience with cloud-native technologies, data analytics, and Kubernetes.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad selection of cloud services and can support many different types of applications and organizations. Its wide range of services would give me flexibility when developing and deploying cloud-based systems.
