# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is AWS because it provides a broad range of cloud services. I also found its services useful for different types of applications and organizations.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP all provide cloud computing services such as virtual machines, storage, networking, databases, and identity management. They also provide scalable infrastructure that organizations can use without maintaining all of their own physical hardware.

## 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud provider is most appropriate for a particular organization. Factors such as budget, existing technologies, application requirements, scalability, location, and specialized needs such as AI or Kubernetes can influence the decision.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider is not simply about selecting the most popular platform. A Cloud Solutions Consultant needs to understand the client's requirements and compare the available services before recommending an appropriate solution.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub Cloud Computing Portfolio improved because I added organized documentation about AWS, Azure, and GCP. I also added comparisons, client recommendations, a decision matrix, and Linux investigation results, making the portfolio more complete and useful for demonstrating my cloud computing knowledge.
