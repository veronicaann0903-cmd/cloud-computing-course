# Google Cloud Platform Research

## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that provides services for computing, storage, networking, databases, data analytics, artificial intelligence, and application development. Organizations can use GCP to build, deploy, and manage applications and workloads using Google's cloud infrastructure.

## 2. Global Infrastructure

Google Cloud operates a global infrastructure organized into regions and zones. Regions represent geographic locations, while zones are deployment areas within regions that help organizations design reliable and highly available applications.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources. It provides access to cloud services and tools for managing projects, applications, and infrastructure.

## 4. Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run applications and workloads in Google Cloud.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store and retrieve files, application data, backups, and other types of data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow organizations to create and manage networks for their cloud resources.

### 4. Cloud SQL

Cloud SQL is a managed relational database service that allows applications to use relational databases without requiring users to manage the underlying infrastructure.

## 5. Three Advantages

1. GCP provides strong capabilities for data analytics and artificial intelligence.
2. GCP provides scalable cloud infrastructure for applications and workloads.
3. GCP provides managed services that can simplify application development and infrastructure management.

## 6. Typical Enterprise Use Cases

GCP can be used by enterprises for application hosting, data storage, data analytics, artificial intelligence and machine learning, database management, website hosting, and scalable business applications.
