# Laboratory Activity 1 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the fundamentals of working in a Linux environment and creating a professional Cloud Computing portfolio using GitHub.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed the Ubuntu Linux environment using KillerCoda.
- Created the required Linux user account.
- Added sudo privileges to the user.
- Logged in to the new user account.
- Checked the username, working directory, and hostname.
- Gathered Linux system information.
- Created the required workspace directories.
- Created Markdown documentation.
