# Mission Reflection

This laboratory activity introduced me to the basic responsibilities involved in working with a Linux environment and maintaining a professional cloud computing portfolio. I learned how to access a Linux environment, create a new user account, assign sudo privileges, and log in using the newly created account.

I also learned how to use Linux commands to gather important system information. Commands such as `whoami`, `pwd`, and `hostname` helped me identify the current user, working directory, and computer hostname. I also used commands such as `uname`, `lscpu`, `free`, and `df` to examine the operating system, kernel, CPU, memory, and disk information.

Another important part of the activity was organizing information using Markdown and GitHub. Creating files and folders with a clear structure helped me understand how technical documentation can be organized in a professional portfolio. I also learned that screenshots are important evidence because they show the actual work performed during the laboratory.

Overall, this activity helped me become more comfortable with Linux commands, user management, file organization, Markdown documentation, and GitHub. These skills provide a useful foundation for future cloud computing activities.
